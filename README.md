## 📖 О проекте

**Glitify** — это мощная платформа для программирования, основанная на **DashBlocks**, **TurboWarp** и других модификациях **Scratch**. 

Мы создаём среду, в которой юные и опытные разработчики могут творить без ограничений. Glitify добавляет в привычный Scratch то, чего ему так не хватало:
- 🧩 **Новые блоки** для сложной логики;
- 🎨 **Продвинутые костюмы и звуки**;
- 🎭 **Уникальных персонажей**;
- ⚙️ **Расширенные функции** для работы с холстом.

Проект разрабатывается командой **LetMeow LLC**.

## 🚀 Особенности Glitify

| Функция | Описание |
| :--- | :--- |
| **Высокая скорость** | Благодаря движку TurboWarp, проекты работают плавно и без лагов. |
| **Кастомные расширения** | Поддержка пользовательских блоков и интеграций. |
| **Тёмная и светлая темы** | Комфортная работа в любое время суток. |
| **Экспорт проектов** | Возможность выгружать свои игры и приложения в разных форматах. |
| **Сообщество** | Встроенный форум и система обмена проектами. |

## 🤝 Как помочь проекту

Мы всегда рады новой помощи! Если ты разработчик, дизайнер или просто хочешь предложить идею:

1. Прочитай наш **[Кодекс поведения](CODE_OF_CONDUCT.md)**.
2. Ознакомься с **[Правилами для контрибьюторов](CONTRIBUTING.md)**.
3. Создай **Issue** с описанием проблемы или предложением.
4. Сделай **Fork** репозитория и отправь **Pull Request**.

> ⚠️ **Внимание:** Мы не принимаем изменения, которые нарушают авторские права или содержат вредоносный код.
