# Безопасность

## Пожалуйста, помогите сохранить безопасность этого курса и его учеников.

# Сообщение об уязвимостях

Не создавайте публичный запрос (issue) по поводу проблем безопасности.

О проблемах безопасности сообщайте конфиденциально владельцу репозитория или контактному лицу из числа сопровождающих, указанному для этого проекта. Включите в сообщение:

· краткое описание;
· затронутый файл или рабочий процесс (workflow);
· шаги для воспроизведения проблемы (если это безопасно);
· потенциальное влияние (последствия);
· предложения по исправлению (если они известны).

Не включайте в отчет реальные токены, учетные данные, данные клиентов или детали о конкретных частных организациях.

# Безопасность материалов

Перед тем как добавлять скриншоты, промпты (запросы), примеры для canvas, примеры автоматизации или вывод терминала, убедитесь, что они не содержат конфиденциальной информации: используйте анонимизированные аккаунты и тестовые данные, скрывайте личные данные, такие как имена пользователей, аватары, адреса электронной почты и локальные пути к файлам.

Никогда не публикуйте:

· токены GitHub;
· ключи API;
· учетные данные провайдеров моделей;
· названия приватных (закрытых) репозиториев;
· данные клиентов;
· детали внутренней политики организации;
· URL-адреса приватных серверов.
